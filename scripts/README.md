# S3011 Perennial Sorghum Analysis Scripts

This directory contains the R scripts used to reproduce the analyses presented in:

**Nabukalu et al.**

*Genetic Architecture of Rhizome Development in Diploid Perennial Sorghum Reveals Candidate Regions Supported by Local Ancestry.*

---

## Analysis Workflow

The scripts should be executed sequentially in the following order:

### 00_setup.R
Project initialization, directory setup, package loading, and reproducibility diagnostics.

### 01_genotype_QC.R
Quality control and filtering of genotype data.

### 02_aggregate_accession_genotypes.R
Aggregate individual-plant genotype calls into accession-level mean allele dosages.

### 03_BLUP_estimation.R
Estimate accession-level best linear unbiased predictors (BLUPs) using REML-based linear mixed models.

### 04_GWAS.R
Perform exploratory genome-wide association analyses using accession-level BLUPs.

### 05_marker_based_genome_scan.R
Perform complementary marker-based genome scans to prioritize candidate genomic intervals.

### 06_GWAS_marker_overlap.R
Compare candidate intervals identified by GWAS and marker-based genome scans.

### 07_candidate_gene_annotation.R
Annotate genes located within prioritized candidate intervals.

### 08_local_ancestry_analysis.R
Analyze local ancestry patterns surrounding candidate genomic regions and quantify ancestry–phenotype relationships.

### 09_LD_analysis.R
Characterize linkage disequilibrium surrounding candidate intervals.

### 10_haplotype_analysis.R
Evaluate multilocus dosage-profile (haplotype) effects associated with candidate genomic regions.

### 11_historical_QTL_comparison.R
Compare candidate genomic intervals with previously reported perenniality QTL from the literature.

### 12_generate_manuscript_figures.R
Assemble publication-quality figures and generate a manuscript figure manifest.

### 13_session_information.R
Record session information, package versions, file checksums, Git metadata, and other reproducibility information.

---

## Pipeline Outputs

The pipeline generates:

- accession-level BLUPs
- GWAS results
- marker-based genome scan results
- candidate gene annotations
- local ancestry analyses
- linkage disequilibrium summaries
- haplotype analyses
- historical QTL comparisons
- publication-quality figures
- reproducibility reports

Intermediate files generated by earlier scripts are used as inputs for subsequent analyses.

---

## Reproducibility

The scripts are designed to be executed sequentially. Running the complete pipeline reproduces the analyses, tables, and figures presented in the accompanying manuscript.

The final script (`13_session_information.R`) records:

- R session information
- package versions
- script checksums
- input file checksums
- Git commit information
- reproducibility metadata
