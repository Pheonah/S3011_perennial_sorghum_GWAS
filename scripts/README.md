# S3011 Perennial Sorghum GWAS Analysis Scripts

This directory contains the R scripts used to reproduce the analyses presented in:

**Nabukalu et al.**
*Genetic Architecture of Rhizome Development in Diploid Perennial Sorghum Reveals Candidate Regions Supported by Local Ancestry.*

## Analysis workflow

Scripts should be executed in the following order:

1. `00_setup.R` – Project initialization, directory setup, and reproducibility diagnostics.
2. `01_genotype_QC.R` – Plant-level genotype quality control.
3. `02_aggregate_accession_genotypes.R` – Aggregate plant genotypes into accession-level allele dosage.
4. `03_BLUP_estimation.R` – Estimate accession-level BLUPs using linear mixed models.
5. `04_GWAS.R` – Genome-wide association analysis.
6. `05_GWAS_marker_overlap.R` – Compare GWAS intervals with marker-based genome scan.
7. `06_candidate_gene_annotation.R` – Annotate candidate genes within prioritized intervals.
8. `07_local_ancestry_analysis.R` – Local ancestry analysis and ancestry overlay.
9. `08_make_figures.R` – Generate manuscript figures and supplementary figures.
10. `09_marker_based_genome_scan.R` – Complementary marker-based genome scan.

Intermediate files generated by earlier scripts are used as inputs for subsequent analyses.
